# NouriCircle

NouriCircle is an AI-assisted nutrition and wellness application concept focused on helping users understand meals, build healthier habits, and make everyday nutrition decisions easier.

## MVP

The initial MVP is intended to explore a simple, user-friendly experience around:

- AI-assisted food and meal understanding
- Personalized nutrition insights
- Daily nutrition and wellness tracking
- Practical recommendations and habit support
- A clear mobile-first experience

This repository contains the prototype and development work for **AIID – NouriCircle**.
