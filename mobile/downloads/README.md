# Download NouriCircle for Android

After a successful **Mobile builds → Android APK** run, the workflow updates `NouriCircle-Android-debug.apk` in this folder. Open that file on GitHub and choose **Download raw file**, then transfer it to your Android phone and open it to install. You may need to allow installation from your browser or file manager.

This is a test APK, not a Play Store release. Each cloud build may use a different debug signing key, so Android might require you to uninstall an older test APK before installing a newer one. Uninstalling also removes this app's locally saved data. Backups and account sync are not available in this prototype.

The iOS artifact in Actions runs in an iPhone Simulator on a Mac. It is not a device-installable IPA; iPhone distribution needs Apple signing and provisioning.
